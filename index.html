Getting started

Get Setup for Development

To start developing locally, download PreForm-Server at the link below and add it to your project folder. To connect to your Formlabs account using the web API, make a Dashboard application and request an OAuth token below. The following sections summarize the Python SDK, HTTP fundamentals, and the endpoint reference.

Local

Automate job preparation on a workstation

  1. Download PreFormServer for macOS or Windows from the Formlabs API downloads page.
  2. Start it with an explicit port, commonly 44388.
./PreFormServer.app/Contents/MacOS/PreFormServer --port 44388

curl http://localhost:44388/
curl http://localhost:44388/scene/
.\PreFormServer\PreFormServer.exe --port 44388

curl.exe http://localhost:44388/
curl.exe http://localhost:44388/scene/
Web

Monitor Dashboard-connected printers

  1. Create Formlabs Dashboard application credentials.
  2. Request an OAuth access token with client_credentials.
curl -X POST https://api.formlabs.com/developer/v1/o/token/ \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=$CLIENT_ID" \
  -d "client_secret=$CLIENT_SECRET"

curl https://api.formlabs.com/developer/v1/printers/ \
  -H "Authorization: Bearer $ACCESS_TOKEN"
curl.exe -X POST https://api.formlabs.com/developer/v1/o/token/ `
  -H "Content-Type: application/x-www-form-urlencoded" `
  -d "grant_type=client_credentials" `
  -d "client_id=$env:CLIENT_ID" `
  -d "client_secret=$env:CLIENT_SECRET"

curl.exe https://api.formlabs.com/developer/v1/printers/ `
  -H "Authorization: Bearer $env:ACCESS_TOKEN"

Python SDK

Develop with the Python SDK

The SDK repository includes a minimal Local API helper, generated Local and Web clients, and runnable examples. The generated clients give typed request models; the minimal local package leaves request formatting in your code. Follow these steps to install the SDK, run PreForm-Server, and run a simple API version check. To start PreForm-Server in your python script, see the Hello Server and Hello Web examples below. 

git clone https://github.com/Formlabs/formlabs-api-python.git
cd formlabs-api-python

python3 -m venv .venv
source .venv/bin/activate
python3 -m ensurepip --default-pip

python3 -m pip install -e local-api/minimal-lib
python3 -m pip install -e local-api/lib
python3 -m pip install -e web-api/lib

Python 
import formlabs_local_api as formlabs

configuration = formlabs.Configuration(
    host="http://localhost:44388",
)

with formlabs.ApiClient(configuration) as api_client:
    api = formlabs.APIInfoApi(api_client)
    print(api.get_api_version())
